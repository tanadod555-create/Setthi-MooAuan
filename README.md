# เศรษฐีหมูอ้วน (Setthi MooAuan) 🐷💰

> **แอพบันทึกสินค้า รายรับ-รายจ่าย & สแกนสลิปอัจฉริยะ สไตล์ Kawaii 3D Game UI**  
> ปลดล็อคฟังก์ชันทุกอย่างฟรีสำหรับการใช้งานส่วนตัว สแกนสลิปธนาคารและใบเสร็จสินค้าด้วย **Gemini 2.5 Flash API** ซิงค์ข้อมูลเข้าสู่ **Google Sheets** ส่วนตัวแบบเรียลไทม์ พร้อมมาสคอตน้องหมูอ้วน (Level 1–10) สลับร่างประจำวันและกดสุ่มร่างได้ตามใจ

---

## จุดเด่นของแอป "เศรษฐีหมูอ้วน"

1. **Standalone Single HTML (ดับเบิลคลิกเปิดได้ทันที):**
   - ใช้งานได้ทันทีผ่านไฟล์ `index.html` หรือ `setthi_mooauan.html` โดยไม่ต้องติดตั้ง Node.js หรือเปิด `localhost`
   - รันออฟไลน์ได้ ข้อมูลบันทึกในเครื่องอัตโนมัติ และซิงค์ขึ้น Google Sheets เมื่อต่อเน็ต
2. **AI Vision Slip & Receipt Scanner (Gemini 2.5 Flash):**
   - อ่านสลิปโอนเงินธนาคารไทย (KBank, SCB, KTB, BBL, TTB, GSB, TrueMoney Wallet ฯลฯ)
   - อ่านใบเสร็จสินค้า 7-Eleven, ซูเปอร์มาร์เก็ต, ร้านอาหาร, บิลค่าน้ำค่าไฟ
   - สกัดยอดเงิน, ร้านค้า, วันที่, เวลา, จัดหมวดหมู่อัตโนมัติ พร้อมหน้าต่างตรวจสอบและยืนยันก่อนบันทึก
3. **MooAuan Kawaii Design System (DESIGN.md):**
   - **Dual Themes:** Strawberry Mochi (ธีมชมพูมะนาว) และ Soda Pop Arcade (ธีมฟ้าแม็กนั่ม)
   - ปุ่มสัมผัสนุ่มสไตล์ 3D Candy Button พร้อมฟีดแบ็กตอนกด
   - มาตรวัดวงแหวนควบคุมงบประมาณรายวัน (Circular Budget Gauge)
4. **Mascot Pig Level 1–10:**
   - ใช้ภาพเรนเดอร์ PNG ความละเอียดสูง เลเวล 1 ถึง 10 จากโฟลเดอร์ `./mascots/`
   - สุ่มร่างตามวันอัตโนมัติ พร้อมปุ่ม **🎲 สุ่มร่าง** ให้กดเปลี่ยนร่างได้ตลอดเวลา
5. **Google Sheets As Database (ฟรีตลอดชีพ 100%):**
   - บันทึกลง Google Sheet ส่วนตัวผ่าน Google Apps Script Web App (`Code.gs`)
   - ปลอดภัย เป็นส่วนตัว 100% และตรวจสอบแก้ไขได้ตลอดเวลา

## วิธีเริ่มใช้งานแอป (Quick Start)

### วิธีที่ 1: ดับเบิลคลิกเปิดใช้งานทันที (แนะนำ)
ดับเบิลคลิกที่ไฟล์ `index.html` หรือ `setthi_mooauan.html` ในโฟลเดอร์นี้เพื่อเปิดบนเบราว์เซอร์ได้ทันที!

---

### วิธีที่ 2: วิธีเชื่อมต่อ Google Sheets ให้เป็นดาต้าเบสส่วนตัว (ใช้เวลา 2 นาที)
1. เปิด [Google Sheets](https://sheets.google.com/) แล้วสร้างไฟล์ชีตใหม่ (ตั้งชื่อว่า `เศรษฐีหมูอ้วน DB`)
2. ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
3. ลบโค้ดเริ่มต้นทั้งหมด แล้วนำโค้ดจากไฟล์ `Code.gs` ในโฟลเดอร์นี้ไปวางแทนที่
4. กดบันทึก (แผ่นดิสก์)
5. กดปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้ใหม่ (New deployment)**
6. เลือกประเภท: **เว็บแอป (Web app)**
7. กำหนดค่า:
   - **เรียกใช้ในฐานะ (Execute as):** `ฉัน (Me)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)`  *(สำคัญมาก)*
8. กด **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **URL เว็บแอป (Web App URL)**
9. เปิดแอปเศรษฐีหมูอ้วน กดปุ่ม ⚙️ (Settings) ด้านบนขวา นำ URL ไปวางในช่อง **Google Apps Script Web App URL**

---

### วิธีที่ 3: วิธีรับ Gemini API Key ฟรี
1. ไปที่ [Google AI Studio (API Keys)](https://aistudio.google.com/app/apikey)
2. เข้าสู่ระบบด้วยบัญชี Google แล้วกด **Create API key**
3. คัดลอกคีย์มาใส่ในหน้า ⚙️ (Settings) ของแอปเศรษฐีหมูอ้วน (ฟรี 15 requests/นาที และ 1,500 requests/วัน)
